# Lightweight React Template for KAVIA

This project provides a minimal React template with a clean, modern UI and minimal dependencies.

## Integrated Design Home Screen

The static HTML/CSS/JS provided from Figma has been integrated as a React component:

- Component: `src/components/Home/Home.jsx`
- Scoped styles: `src/components/Home/Home.module.css` and `src/components/Home/common.module.css`
- Assets: `src/assets/figmaimages/*` (see PLACEHOLDER.txt for expected files)

The Home screen is rendered as the root view via `src/App.js`.

## Getting Started

In the project directory, you can run:

### `npm start`

Runs the app in development mode.\
Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

### `npm test`

Launches the test runner in interactive watch mode.

### `npm run build`

Builds the app for production to the `build` folder.\
It correctly bundles React in production mode and optimizes the build for the best performance.
